# Support

Thanks for your interest in **rommsync-nx**.

rommsync-nx is a background sysmodule and an Ultrahand overlay that sync a
modded Switch with your own RomM server. It ships as a release zip from the
[Releases](https://github.com/armaatus/rommsync-nx/releases) page; it has not
yet been validated on a real console, which the install guide says up front.

## Where to go

- **Install it** → [`docs/INSTALL.md`](docs/INSTALL.md), and
  [`docs/INTEROP.md`](docs/INTEROP.md) for the other devices that share your
  saves.
- **Something does not work** → [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)
  first: find the line your log shows. If that does not settle it, open a
  **Bug report** -- it asks for the versions and files the troubleshooting
  guide names.
- **Understand the project** → start with the [README](README.md), then
  [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
- **Questions & ideas** → open a
  [Discussion](https://github.com/armaatus/rommsync-nx/discussions) (if enabled)
  or an issue using the **Intent** template.
- **Want to contribute** → read [CONTRIBUTING.md](CONTRIBUTING.md) and pick an
  issue labelled `ready`.
- **Security vulnerability** → do **not** open a public issue; follow
  [SECURITY.md](SECURITY.md).
- **Bug in RomM itself** → report upstream at
  [rommapp/romm](https://github.com/rommapp/romm/issues).

Please remember this is a volunteer project — responses are best-effort.
