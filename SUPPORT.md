# Support

Thanks for your interest in **rommsync-nx**.

This project is in **pre-release** — the Switch client isn't implemented yet, so
there's nothing to install or run on-console today. What exists is the
server-side contract, the docs, and the issue backlog.

## Where to go

- **Understand the project** → start with the [README](README.md), then
  [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
- **Questions & ideas** → open a
  [Discussion](https://github.com/armaatus/rommsync-nx/discussions) (if enabled)
  or a normal issue using the **Task** template.
- **Want to contribute** → read [CONTRIBUTING.md](CONTRIBUTING.md) and pick an
  issue from milestone **M0/M1**.
- **Security vulnerability** → do **not** open a public issue; follow
  [SECURITY.md](SECURITY.md).
- **Bug in RomM itself** → report upstream at
  [rommapp/romm](https://github.com/rommapp/romm/issues).

Please remember this is a volunteer project — responses are best-effort.
